Chrome extension that re-ranks YouTube search results by analyzing comment sentiment — surfacing videos praised for clarity or confirmed as legit, and flagging ones with confusion or clickbait complaints, instead of sorting by views.

Key points

- Lightweight and focused — minimal dependencies.
- Easy to run and integrate into existing workflows.

Quick start

Clone the repo:
   git clone https://github.com/Insight14/Comment-Sense.git

Get API Keys:
   Use your own YouTube Data API from Google Cloud Console, and Google Gemini API from Google AI Studio
